# Crazi-AutoClicker
made a free to use auto clicker bc everything else is a virus 😭
make SURE you have .NET 8.0 Windows Desktop Runtime installed. If you don't, this app won't work

# HOW TO USE:
Click on "Start" to start the autoclicker
Click on "Stop" to stop the autoclicker

# CHANGELOGS:
nothing, but I do plan adding a thing where you can change how many times you click
